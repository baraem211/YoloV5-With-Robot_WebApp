📌 프로젝트 소개

COCO-SSD(TensorFlow.js)로 웹캠에서 실시간 객체를 탐지하고, 탐지된 객체에 따라 휴머노이드 로봇의 모션을 자동 실행합니다.

💡 핵심 파이프라인
  • 웹캠 영상 → COCO-SSD 추론 → 라벨 매핑 → MotionSequencer → 로봇 패킷 전송
  • 포트 선택 팝업 · 115200bps (Web Serial API 연결 시 실물 로봇 제어)
  • LABEL_TO_MOTION 매핑 테이블로 어떤 객체든 원하는 모션에 연결 가능

🔄 동작 흐름

[1] 페이지 로드 → COCO-SSD 모델 자동 로드
[2] 카메라 권한 요청 → 웹캠 스트리밍 시작
[3] 매 프레임: model.detect(video) → predictions[]
[4] confidence ≥ threshold 인 객체만 필터링
[5] LABEL_TO_MOTION에 매핑된 객체 발견 시
    → MotionSequencer.trigger(motionId)
[6] 시퀀서: ACTION(7초) → RETURN(3초) → IDLE
[7] 각 단계마다 HumanoidRobot.buildPacket(id) 전송

🗺️ LABEL_TO_MOTION 매핑

COCO-SSD가 인식하는 80가지 클래스 중 원하는 객체에 모션 번호를 연결하세요.

LABEL_TO_MOTION = {
  "person":     19,  // 👤 사람 → 인사
  "bottle":     18,  // 🍾 병  → 손흔들기
  "cell phone": 20,  // 📱 폰  → 커스텀
}

신뢰도 슬라이더로 조정하세요. ACTION_HOLD_SEC를 늘리면 중복 실행을 방지합니다.
